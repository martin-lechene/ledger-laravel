# Contributing

Thanks for your interest in `martin-lechene/ledger-laravel`.

1. Fork the repository and create a branch from `main`.
2. Install dependencies: `composer install`.
3. Make your change with tests. Run `vendor/bin/phpunit` (or `composer test`).
4. Use conventional commit messages (`feat:`, `fix:`, `docs:`, `chore:`).
5. Update `CHANGELOG.md` under `[Unreleased]` and open a pull request.

Never commit secrets, keys, `.env` files or real wallet data. Report security issues privately, see `SECURITY.md`.
