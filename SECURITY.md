# Security Policy

## Reporting a vulnerability

This package handles hardware wallet operations. Please report vulnerabilities **privately**
to contact@doganddev.eu (or via GitHub private vulnerability reporting if enabled on the repository).
Do not open a public issue. Include the affected version or commit, reproduction steps and impact.

You will get an acknowledgement as soon as possible; this is a small project maintained on a best-effort basis.

## Supported versions

The package is in beta and has no tagged release yet. Only the latest commit on `main` receives fixes.

## Never share

Seed phrases, private keys, bridge tokens or real transaction data, in reports or elsewhere.
